# NotchStar

NotchStar is a native Mac app that puts ten small tools in the MacBook notch. Hover over the notch and it opens: clipboard history, a file shelf with AirDrop, now playing, calendar and reminders, timers, a teleprompter, a camera mirror, system stats, disk tools and quick notes. A Screenshot Tray keeps each new screenshot under the notch so you can drag it into a chat, an email or a folder.

Website: https://www.notchstar.com

## Download

Get the latest signed and notarized disk image from [Releases](https://github.com/ArinPrajapati/notchstar-feedback/releases/latest) or from https://www.notchstar.com/download/. Each release lists the SHA-256 checksum. Verify it with `shasum -a 256 NotchStar-1.0.5.dmg`.

## The ten tools

1. Home, with Now Playing
2. Shelf, with AirDrop
3. Clipboard history (up to 50 items, in memory only, skips items a password manager marks as concealed)
4. Calendar and Reminders
5. Quick Notes
6. Timers
7. Teleprompter
8. Mirror
9. System stats
10. Disk (everything it removes goes to the Trash)

## Screenshot Tray

Screenshots wait under the notch. Drag one into a chat, an email, a folder or the Shelf. Command click picks several, and Option drag sends them all. The tray holds the latest 12, each for five minutes unless you use it. Leaving the tray never touches the file.

## Privacy

No account. Nothing is measured unless you opt in to anonymous version info. Details: https://www.notchstar.com/privacy/ and https://www.notchstar.com/guides/is-notchstar-safe/
